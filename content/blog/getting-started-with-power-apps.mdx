## What is Power Apps?

Power Apps is Microsoft's low-code application development platform. It lets you build business apps without traditional coding — though knowing some code (Power Fx) helps a lot.

## Canvas App vs. Model-Driven App

| Feature | Canvas App | Model-Driven App |
|---|---|---|
| **Design control** | Full pixel-level control | Pre-built layouts |
| **Data source** | Any (SharePoint, SQL, API) | Dataverse only |
| **Best for** | Custom UX, specific workflows | Data-heavy CRUD apps |
| **Learning curve** | Lower | Higher |

For most business applications, **Canvas Apps** are the way to go.

## Your First App: Step by Step

### 1. Plan Your Screens

Don't open Power Apps yet. Sketch your screens on paper first:
- What data does the user need to see?
- What actions can they take?
- What happens after each action?

### 2. Set Up Your Data Source

Start with SharePoint lists — they're simple and free with your M365 license.

### 3. Build the UI

Use galleries for lists, forms for data entry, and navigation for multi-screen apps.

### 4. Add Logic

Power Fx is similar to Excel formulas. If you know Excel, you can learn Power Fx.

### 5. Test and Publish

Test on both desktop and mobile. Then publish and share via Teams.

## Common Mistakes to Avoid

- Don't put too many controls on one screen
- Don't skip error handling
- Don't forget mobile responsiveness
- Don't hardcode values — use variables and collections
